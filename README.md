# Telegram-бот записи клиентов

Бот для малого бизнеса: салона красоты, барбершопа, автосервиса, репетитора, мастера на дому. Клиент сам записывается на свободное время, владелец получает заявку в Telegram и подтверждает её одной кнопкой. Все записи сохраняются в Excel.

## Возможности

**Для клиента**
- Запись в несколько нажатий: услуга → дата → свободное время → имя → телефон
- Показывает только реально свободные слоты: занятые и прошедшие скрыты, выходные учитываются
- Номер телефона — одной кнопкой «Отправить мой номер» или вручную, с проверкой формата
- «Мои записи»: список предстоящих визитов со статусом и отменой в один клик
- Разделы «Услуги и цены» и «Контакты», справка `/help`
- Уведомление, когда запись подтвердили или отклонили

**Для владельца**
- Новая заявка сразу приходит в Telegram — лично или в рабочую группу
- Кнопки «Подтвердить» / «Отклонить» прямо в уведомлении, клиент получает ответ автоматически
- Уведомление, если клиент отменил запись
- Отдельное меню владельца: кнопки «Записи на сегодня» и «Выгрузка в Excel» (то же командами `/today` и `/export`)
- Выгрузка всех записей в Excel: дата, время, услуга, цена, клиент, телефон, статус
- Подсказки команд при вводе «/»: клиент видит только свои, владелец — ещё и команды управления

**Надёжность**
- Защита от двойной записи: время перепроверяется в момент подтверждения
- Данные пишутся атомарно, файл не портится при внезапной остановке
- Не нужна база данных и платный хостинг: достаточно любого компьютера или VPS

## Под любой бизнес за 5 минут

Всё, что относится к конкретному бизнесу, собрано в одном файле [`src/config.ts`](src/config.ts): название, адрес, телефон, услуги с ценами, рабочие часы, шаг записи, выходные, горизонт записи.

## Стек

TypeScript · Node.js · [grammY](https://grammy.dev) · ExcelJS

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN`.
4. Запустите бота:
   ```bash
   npm start
   ```
5. Отправьте боту `/myid`, впишите полученное число в `ADMIN_CHAT_ID` в `.env` и перезапустите бота. Чтобы заявки приходили в рабочую группу, добавьте бота в группу и отправьте `/myid` там.

Для постоянной работы бот запускается на VPS через `pm2` или `systemd`.

## Структура

```
src/
  bot.ts        логика диалога, уведомления, команды владельца
  config.ts     настройки бизнеса: услуги, цены, расписание
  schedule.ts   расчёт свободных дат и слотов
  storage.ts    хранение записей и выгрузка в Excel
```
